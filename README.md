# Rock Paper Scissors Game (Python)

This project is a simple Rock Paper Scissors game built in Python.
The game allows a user to play against the computer, which randomly selects Rock, Paper, or Scissors.
It’s a beginner-friendly project useful for learning Python basics, user input, loops, and condition logic.

#Features

.Play Rock Paper Scissors vs Computer
.Random computer choice generation
.Input validation
.Win / Lose / Draw result display
.Simple and beginner-friendly code
.Runs in terminal or Jupyter Notebook

# How It Works

.User chooses Rock, Paper, or Scissors
.Computer randomly selects an option
.Game compares both choices

#Result is displayed:
Win 
Lose 
Draw 

#Learning Objectives

.This project helps beginners understand:
.Python input/output
.if-else conditions
.loops
.random module
.basic game logic
